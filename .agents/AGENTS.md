# Project Rules & Memory

## Kế hoạch phát triển (Development Plan)
Khi user hỏi về "kế hoạch phát triển", hãy nhớ và đề xuất danh sách các tính năng dự định làm sau đây:
- Mã giảm giá / Voucher (Coupons) 🎟️ (Giúp kích thích doanh số)
- Sản phẩm Yêu thích (Wishlist) ❤️ (Giữ chân khách hàng tiềm năng)
- Hệ thống Thông báo (Notifications) 🔔 (Tương tác khách hàng theo thời gian thực)
- Biểu đồ thống kê nâng cao cho Admin (Dashboard Analytics) 📈 (Dành cho việc phân tích và quản lý)
- Tích hợp cổng thanh toán VNPay
- Chống spam đăng nhập, gửi form liên hệ (Rate limiting / reCAPTCHA)
